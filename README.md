# Chefly – Mobile-first recipe generator

Chefly is a mobile-forward web app that generates realistic recipes from cuisine and dietary preferences or a custom prompt. Generated recipes include hero imagery, ingredients, step-by-step instructions, timing, and difficulty. Saved recipes can be organized into custom recipe books for easy retrieval.

## Features
- Multi-select cuisine and dietary chips plus a free-text prompt to guide recipe generation.
- Automatic hero image, title, tags, ingredients, steps, prep/cook time, servings, and difficulty.
- Save, delete, and organize recipes into custom recipe books.
- Mobile-first UI with a persistent bottom navigation bar.
- LocalStorage persistence for recipes and recipe books.

## Getting started
```bash
npm install
npm run dev
```
Then open the local URL printed in the terminal.

## Tech
- React + Vite
- Modern, component-based styling tuned for mobile.
